## Residual Severity Considered in This Work

Two sources of RS are used, and both enter the same fitness function.

- **CSV mode:** RS is the pre-computed table value for a signature–defense pair, an integer from 0 to RS<sub>max</sub> = 10 (values 0 to 6 occur), normalized by RS<sub>max</sub>. This mode is used for all method comparisons.
- **LLM mode:** RS is the MiST-8B estimate for one signature–defense pair, an integer from 0 to that signature's original Cuckoo severity V<sub>k</sub> (1 to 6 in our data): RS = 0 means no severity is left and RS = V<sub>k</sub> means the defense does not reduce the behavior. It enters the fitness through the LLM-mode rule RM<sub>k</sub> = AM<sub>k</sub> · RS / V<sub>k</sub>. This mode is used in the Sample02 case study.

## (1) Residual-Severity Estimation Metrics

For *n* signature–defense pairs, let ŷ<sub>i</sub> be the predicted and y<sub>i</sub> the reference residual severity. Both are integers on the RS scale of this work: from 0 (nothing left) up to RS<sub>max</sub> = 10, the upper bound of the scale (in LLM mode the values stay at or below V<sub>k</sub> ≤ 6). All metrics use this one scale, so that results for different signatures can be pooled.

Each run reports the numbers of eligible, skipped, invalid, failed and successful cases. Reference labels are assigned independently of the model, and examples used while developing the prompt are kept out of the evaluation set.

## (2) Optimization Metrics

- MSS<sub>before</sub> = IS and MSS<sub>after</sub> = RA(C*) place before and after on the same 0–1 scale.
- F* = (IS − RA(C*)) / IS is the fraction of severity removed.
- **Shapiro–Wilk** tests the normality of paired differences (normality rejected if p < 0.05).
- The **Wilcoxon signed-rank test** is a non-parametric paired test, significant if p < 0.05. It is applied to CCEA vs. random search and to MSS<sub>before</sub> vs. MSS<sub>after</sub>.
- Wilcoxon is used for all comparisons regardless of the normality result, so every comparison is reported with the same test. Wilcoxon p-values are exact; pairs with zero difference are discarded before ranking.

| Test | Question it answers | Decision rule |
|:---|:---|:---|
| **Shapiro–Wilk** | Are the paired differences normally distributed? | Normality rejected if p < 0.05 |
| **Wilcoxon signed-rank** | Do CCEA and random search (or before and after) differ systematically? | Difference significant if p < 0.05 |

## Baseline: Equal-Budget Random Search

CCEA is compared with a **random-search baseline** run on exactly the same inputs. Random search draws as many uniformly random combinations as CCEA evaluated for the same sample. Both methods use:

- the same candidate pools P<sub>k</sub> from the candidate dataset D (17 samples, 2,791 valid rows);
- the same RS source (CSV mode, the same RS table);
- the same validator and fitness definition.

Because the inputs are identical, any difference in MSS<sub>after</sub> or fitness reflects the search alone. Each sample therefore yields a paired result: one value for CCEA and one for random search.

## Experimental Protocol

| Item | Setting |
|:---|:---|
| **Data** | The 2,791 valid rows of D (17 samples) |
| **RS source** | CSV mode for all methods, so the inputs are identical. RS is an integer on the scale 0 to 10 (the values in the table are 0 to 6) and is normalized by RS<sub>max</sub> = 10. The current table's values are provisional until LLM-mode values replace them. |
| **Parameters** | G<sub>max</sub> = 100, τ = 20, p<sub>e</sub> = 0.25, p<sub>m</sub> = 0.20, δ = 10⁻⁸, ε = 0.03, seed 42 + i |
| **Baseline** | Random search with the same number of evaluations as CCEA |
| **Ablation** | Larger budgets (G<sub>max</sub> / τ = 500 / 100 and 2000 / 500) |
| **Seed stability** | 30 seeds per sample |
| **Tests** | Paired Shapiro–Wilk on the differences, then Wilcoxon signed-rank (α = 0.05) |
